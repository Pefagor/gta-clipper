# История версий

Схема: **0.MINOR.PATCH** — MINOR растёт при новых возможностях, PATCH — при исправлениях.
**1.0.0** — когда программа обкатана и готова к релизу GTA 6. Сборка (номер коммита и время) показывается
рядом с версией в боте (/start, 📊 Статус), в консоли и в `doctor`.

## 0.12.0
- YouTube-эфиры: каналы YouTube (`https://youtube.com/@канал`) пишутся рядом с Twitch, эфир находится
  автоматически, в списке каналов — ▶️YT, подпись «YouTube: Канал» на видео и ссылка в пакете публикации.
- Чат YouTube-эфира через официальный YouTube Data API (ключ YOUTUBE_API_KEY, квота учтена: опрос раз в 30 с,
  детектор смотрит с запаздыванием опроса; при исчерпании квоты — пауза и уведомление). `doctor` проверяет ключ.
- Исправлено: звук, приходящий пачками (YouTube отдаёт эфир кусками по ~5 с), детектор считал тишиной.

## 0.11.0
- Понятные ошибки: вместо трассировок и английских текстов — что случилось и что делать (routerai: ключ,
  баланс, модель; YouTube: приватное, 18+, «не бот», удалено, гео; Twitch: только для подписчиков, офлайн;
  Whisper без библиотек видеокарты; ffmpeg без субтитров/NVENC; место на диске; Telegram: токен, вторая
  копия бота, нет связи; ошибки в config.yaml — с файлом и строкой). Трассировки — только в data/logs/app.log.
- Консоль: сводка при запуске (что включено и почему нет), цвета (предупреждения жёлтым, ошибки красным),
  ник канала в каждом сообщении о клипе, «попытка N из M» при повторах, итог каждые 15 минут.
- Исправлено: при остановке программы оставались висеть процессы проверки эфира.

## 0.10.0
- «🔗 Видео» в боте: ссылка на YouTube, запись стрима Twitch или свой файл.
  - ⭐ Лучшие моменты: «самые пересматриваемые» места YouTube, крики, чат записи стрима и Haiku по расшифровке
    всего видео → обычный конвейер (Sonnet, монтаж, модерация).
  - 🧩 Нарезка на части ~75 с по паузам в речи, «ЧАСТЬ N/M» на видео, заголовки и оценки частей от Haiku;
    проходные части — в «Отсеянные».
- Подпись источника на видео и в пакете публикации; позиция в исходном видео в карточке.
- Нужен deno (yt-dlp для YouTube): Windows — `winget install DenoLand.Deno`, Mac — `brew install deno`.

## 0.9.0
- Заголовки и надписи называют стримера по имени, а не «стример»; в карточке канала «✏️ Имя в заголовках»
  (как его знают зрители), по умолчанию — имя с Twitch.
- Надпись в начале видео: жёлтая, без фона, с чёрной обводкой.

## 0.8.0
- Своя надпись в начале видео, отдельно от заголовка публикации: в карточке модерации «🔤 Надпись на видео»
  (своя / без надписи / как заголовок).

## 0.7.3
- Версия программы в /start, в 📊 Статус, в консоли при запуске и в `doctor`; этот файл.

## 0.7.2
- routerai 401: кандидаты не сгорают, а ждут исправления ключа; `doctor` делает пробный запрос к моделям;
  ключ из `.env` очищается от кавычек и невидимых символов.

## 0.7.1
- Вебка попадает в монтаж только после подтверждения в боте (✅ Верно).

## 0.7.0
- Рамка вебки по присланной вырезке со скриншота; подстройка каждого края отдельно.
- Мягкая проверка вебки перед монтажом (по краям рамки); поиск вебки стартует через ~35 с.
- Субтитры не прыгают: фиксированная позиция, без наложений по времени, всегда одна строка.

## 0.6.0
- Раздел «🗂 Отсеянные»: причина отказа, просмотр фрагмента, возврат в работу.
- macOS: Whisper на графическом ядре Apple Silicon (MPS); раздел установки на macOS в README.

## 0.5.0
- Режимы вебки: авто / выкл / заставка (картинка или видео), общий и для каждого канала.

## 0.4.0
- Не только GTA 6: игра определяется по категории стрима, подставляется в промпты, заголовки, хэштеги,
  подборки группируются по игре.

## 0.3.0
- Понятные пошаговые сообщения в консоли; команда `queue`.
- Windows: ffmpeg из папок winget, streamlink в виртуальном окружении, DLL CUDA для Whisper,
  исправлена установка `pip install -e .`; routerai мимо системного прокси.
- Вебка учитывает композицию кадра (не захватывает панели интерфейса).

## 0.2.0
- Вебка: детектор лиц YuNet, поиск настоящих краёв рамки, ручная подстройка, проверка перед монтажом.
- Рейдж-моменты: крик без реакции чата, окно по секунде крика, метки (КРИК) для ИИ, категория «рейдж».

## 0.1.0
- Первая версия: параллельная запись стримов, детектор моментов (чат, звук, клипы зрителей), вырезка,
  Whisper, отбор Haiku → Sonnet через routerai, монтаж 9:16 с субтитрами, Telegram-бот.
