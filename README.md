# gta-clipper

Программа пишет стримы Twitch (несколько каналов параллельно), прямо во время эфира находит интересные моменты,
отбирает их через ИИ (Claude Haiku → Sonnet через routerai.ru), рендерит вертикальные клипы 1080×1920 с
субтитрами и присылает их в Telegram на модерацию. Одобренные клипы приходят пакетами для ручной публикации
в YouTube Shorts и TikTok.

## Как это работает

```
streamlink → ffmpeg ─┬─ сегменты по 4 с (буфер 3 часа, без перекодирования)
                     └─ звук → громкость
чат Twitch (IRC) ────┐
клипы зрителей (API) ┼─► детектор (раз в 2 с) ─► кандидат ─► вырезка ─► Whisper
громкость ───────────┘                                        │
                         Haiku: «есть ли момент» ─► Sonnet: границы, заголовки, спойлер
                                                              │
                         рендер 9:16 (ffmpeg) ─► Telegram: ✅/❌/✂️/📝 ─► пакет для публикации
```

Путь кандидата: `to_cut → cut → transcribed → screened → to_render → rendered (модерация) → approved →
sent (пакет отправлен) → done`, либо `rejected / discarded / failed`.

## Установка на Windows

1. В PowerShell, по одной команде:
   ```
   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   winget install Git.Git
   ```
   Сборка Gyan.FFmpeg уже умеет субтитры (libass) и кодировщик видеокарты NVIDIA (NVENC).
2. Скачайте проект и создайте виртуальное окружение:
   ```
   git clone https://github.com/Pefagor/gta-clipper.git
   cd gta-clipper
   py -3.12 -m venv .venv
   ```
3. Активируйте окружение. Это нужно делать в каждом новом окне терминала; признак успеха — `(.venv)`
   в начале строки. Все команды ниже и в остальном README пишутся уже без пути к `.venv`.
   ```
   .venv\Scripts\activate
   ```
   Если PowerShell пишет, что выполнение сценариев запрещено, один раз выполните
   `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` и повторите активацию.
   На macOS/Linux: `source .venv/bin/activate`.
4. Установите зависимости:
   ```
   pip install -e .
   ```
5. Распознавание речи на видеокарте: faster-whisper использует CUDA 12 и cuDNN 9. Проще всего:
   ```
   pip install nvidia-cublas-cu12 nvidia-cudnn-cu12
   ```
   Если видеокарта не подхватится, программа сама перейдёт на процессор (медленнее, но работает).
6. Скопируйте `.env.example` в `.env` (`copy .env.example .env`) и впишите ключи (как их получить — ниже).
7. Проверьте установку: `python -m clipper doctor`
8. Запуск: `python -m clipper run`

Обновление до новой версии: `git pull`, затем `pip install -e .` (в активированном окружении).

## Установка на macOS

Нужен Homebrew (https://brew.sh). Команды — в «Терминале», по одной.

1. Программы. Нужен именно `ffmpeg-full`: обычный `ffmpeg` из brew не умеет субтитры.
   ```
   brew install ffmpeg-full python@3.12 git
   ```
2. Проект и виртуальное окружение:
   ```
   cd ~/Desktop
   git clone https://github.com/Pefagor/gta-clipper.git
   cd gta-clipper
   python3.12 -m venv .venv
   ```
3. Активируйте окружение — в каждом новом окне Терминала (признак — `(.venv)` в начале строки):
   ```
   source .venv/bin/activate
   ```
4. Зависимости:
   ```
   pip install -e .
   ```
5. Ключи: `cp .env.example .env`, затем `open -e .env` и впишите их (как получить — ниже).
6. Проверка: `python -m clipper doctor` — должно быть `whisper: графическое ядро Apple (MPS)` и
   кодировщик `h264_videotoolbox`.
7. Запуск так, чтобы Мак не засыпал, пока работает программа:
   ```
   caffeinate -dimsu python -m clipper run
   ```

Особенности Мака:
- Whisper работает на графическом ядре Apple Silicon (MPS), ~1.6× быстрее процессора; при ошибке сам
  переходит на процессор. Монтаж — на встроенном кодировщике VideoToolbox.
- MacBook Air без вентилятора при долгой нагрузке сбрасывает частоты: 1–3 канала — нормально, больше — лучше ПК.
- Держите на зарядке, с открытой крышкой и по возможности на проводном интернете.
- **Один Telegram-бот — одна запущенная программа.** Если программа работает и на ПК, и на Маке с одним
  токеном, бот будет сбоить. Для второй машины заведите второго бота в @BotFather.

Обновление: `git pull`, затем `pip install -e .` (в активированном окружении).

## Как получить ключи

### Telegram-бот
1. В Telegram откройте @BotFather → `/newbot` → придумайте имя и ник бота.
2. BotFather пришлёт токен вида `123456:ABC...` — впишите его в `TELEGRAM_BOT_TOKEN`.
3. Запустите программу, напишите своему боту `/start` — он ответит вашим ID. Впишите его в
   `TELEGRAM_OWNER_ID` и перезапустите программу. Управлять ботом сможете только вы.

### Twitch (по желанию, но лучше сделать)
Нужно для учёта клипов зрителей (самый сильный сигнал) и проверки ников при добавлении канала.
1. Войдите на https://dev.twitch.tv/console и включите двухфакторную защиту аккаунта, если Twitch попросит.
2. Applications → Register Your Application. Название любое, OAuth Redirect URL: `http://localhost`,
   категория: Application Integration, тип клиента: Confidential.
3. Откройте приложение → скопируйте Client ID → New Secret → скопируйте секрет.
4. Впишите в `TWITCH_CLIENT_ID` и `TWITCH_CLIENT_SECRET`.

### routerai.ru
1. Зарегистрируйтесь на routerai.ru, пополните баланс.
2. В личном кабинете создайте ключ API и впишите его в `ROUTERAI_API_KEY`.
3. `python -m clipper doctor` проверит, что модели из `config.yaml` (`llm.screen_model`, `llm.review_model`)
   есть в каталоге. Если Haiku называется иначе — поправьте название в `config.yaml`.
4. Цены моделей для подсчёта расходов — `llm.prices_rub` в `config.yaml`.

Без ключа routerai программа тоже работает: ИИ-отбор пропускается, и на модерацию приходит каждый кандидат
целиком (окно ~75 с) с заголовком «Момент со стрима».

## Вебка

При первом эфире канала программа берёт 24 кадра за ~3 минуты и ищет вебку:
1. лица — нейросетевым детектором YuNet (`models/face_detection_yunet_2023mar.onnx`, лицензия MIT, OpenCV Zoo);
2. выбирается лицо, которое стоит на месте почти во всех кадрах и крупнее остальных
   (камеры игроков в трансляциях турниров и «лица» в игре отсеиваются);
3. рамка — прямоугольник вокруг лица, все стороны которого — «постоянные» края (видны почти на всех кадрах,
   пока игра вокруг меняется); край кадра тоже считается стороной.

Поиск запускается через ~35 секунд записи. Если стример отошёл (лица нет) — повтор через 2 минуты.
Вебка попадает в клипы только после вашего подтверждения («✅ Верно»); до него клипы монтируются без вебки.

Бот присылает кадр с рамкой: зелёная — края найдены, жёлтая — примерная оценка по лицу.
Если рамка шире вебки:
- **✏️ Подправить** — кроме сдвига и размера, каждый край двигается отдельно (◀ левый ▶, ▲ верх ▼ и т.д.)
  шагом ~8 пикселей;
- **📸 Прислать вырезку вебки** — скриншот стрима, обрезанный на телефоне ровно по краям вебки. Программа найдёт
  его в кадре стрима (на любом масштабе) и поставит рамку точно по нему. Работает и когда канал офлайн —
  по кадру последнего эфира.

Перед монтажом каждого клипа программа проверяет 8 кадров: вебка на месте, если видны её края (или есть
лицо и края хоть немного видны). Стример, который отвернулся, вебку не выключает; сменилась раскладка —
клип монтируется без вебки.
Кнопки: ✅ Верно, ✏️ Подправить, 📸 Прислать вырезку вебки, 🔄 Искать снова, 🚫 Без вебки.

### Без вебки или заставка вместо неё

Режим вебки: **авто** (искать вебку), **выкл** (игра на размытом фоне) или **заставка** (вместо вебки
сверху ваша картинка или видео; видео крутится по кругу без звука).
- Общий режим и общая заставка — ⚙️ Настройки → «🎥 Вебка по умолчанию» и «🖼 Общая заставка».
- Для канала — в его карточке (📺 Каналы → канал): «🎥 Режим» (по умолчанию → авто → выкл → заставка)
  и «🖼 Своя заставка». Своя заставка канала важнее общей.
- Заставка присылается боту картинкой, видео, GIF или файлом (до 20 МБ); хранится в `data/overlays/`.

## Рейдж-моменты

- Крик громче обычного уровня стримера на `detector.rage_db` (9 дБ) хотя бы секунду создаёт кандидата
  даже при молчащем чате.
- Окно клипа привязывается к секунде крика (для моментов по чату — «сейчас минус задержка чата»).
- В расшифровку для ИИ вставляются метки `(КРИК: громче обычного на N дБ, M с)`, и Sonnet начинает клип
  с причины ора, а заканчивает после реакции.
- Отдельная категория «рейдж» 🤬 — для подборок.

## Управление (Telegram)

Меню внизу экрана: **🎬 Модерация · 📤 Публикация · 📺 Каналы · 📊 Статус · 🗂 Отсеянные · ⚙️ Настройки**.

- **Модерация** — по одной карточке по порядку: ✅ одобрить, ❌ отклонить (с ↩️ возвратом),
  ✂️ сдвинуть начало/конец на ±5 с и перерендерить, 📝 выбрать один из 3 заголовков или свой.
- **Публикация** — пакеты приходят по расписанию (лимит в день и интервал в настройках) или сразу после ✅.
  Тексты в пакете копируются одним касанием. Кнопки «Выложил в Shorts / TikTok», «⏰ Через 1 час»,
  «🗑 Не публиковать». Здесь же «🎞 Собрать подборку» из одобренных клипов на одну тему (60–90 с).
- **Каналы** — добавление по нику или ссылке, пауза, удаление (сразу или после конца стрима),
  настройка вебки. При первом эфире канала бот пришлёт кадр с найденной вебкой на подтверждение.
- **Отсеянные** — кандидаты, которых отбраковал ИИ (Haiku/Sonnet) или которые упали с ошибкой, с причиной.
  Можно посмотреть фрагмент (480p) и вернуть кандидата в работу («♻️ Всё-таки сделать клип»).
  Хранятся `cleanup.keep_rejected_days` (1 день).
- **Настройки** — чувствительность детектора, публикаций в день, интервал, режим публикации, хэштеги,
  лимит расходов на API, тихий режим, пауза всего.

Без Telegram-токена программа тоже работает (для проверки): клипы копятся в `data/candidates/*/clip.mp4`.
Каналы тогда добавляются командой `python -m clipper add <ник>` или `run --channel <ник>`.

## Команды

```
python -m clipper run [--channel ник ...]   запустить
python -m clipper add ник                   добавить канал
python -m clipper remove ник                удалить канал
python -m clipper list                      список каналов
python -m clipper doctor                    проверить установку и ключи
```

## Перед релизом на Windows

- Приостановите обновления Windows на 1–2 недели и отключите сон.
- Добавьте папку `data` в исключения Defender (тысячи мелких файлов в час).
- Нужно ~150 ГБ свободного места на 6 каналов.

## Файлы

```
config.yaml        настройки (пороги, модели, цены, рендер)
.env               ключи (не в git)
clipper/
  app.py           ядро: наблюдатель, детектор, конвейер, уборка
  recorder.py      запись канала (streamlink → ffmpeg)
  segments.py      индекс сегментов и выбор окна
  chat.py          чат Twitch (IRC)
  twitch.py        Twitch API
  detector.py      баллы моментов
  cutter.py        вырезка, кадры, звук
  transcribe.py    Whisper
  llm.py           Haiku/Sonnet через routerai
  render.py        вертикальный рендер и подборки
  camcal.py        поиск вебки (YuNet + края рамки)
  bot.py           Telegram-бот
models/            модель детектора лиц
data/              записи, кандидаты, база, логи (не в git)
```
